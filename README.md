## Project Description

This project is a Python application that connects to a Redis key-value database. It uses a menu that allows the user to perform CRUD operations on Redis sets.

## Features

The application allows users to:

- View the members of a specific set.
- Create a new set and add members.
- Update a set by adding or removing members.
- Remove all members from a set.
- Delete a specific set.
- Delete all data from the selected Redis database.
- Exit the program.

## Python File

**Dickens_RedisMenu.py** — Contains the Python application, Redis connection, and menu options used to perform the database operations.

## Technologies Used

- Python
- Redis
- redis-py
- Ubuntu terminal

## How to Run

Make sure Redis is running and the Python Redis library is installed.

Run the application using:

`python3 Dickens_RedisMenu.py`

Follow the menu prompts to select and perform the database operations.
